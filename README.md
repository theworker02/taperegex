# taperegex

Tape lightweight regex statistics from stdin samples.

**Site:** https://theworker02.github.io/taperegex/

## Install / run

```bash
git clone https://github.com/theworker02/taperegex.git
cd taperegex
node src/cli.js
node --test
```
